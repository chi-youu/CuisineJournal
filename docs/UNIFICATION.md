# 物品统一规则

统一模式使用明确等价组与宿主路径，不按显示名称或宽标签自动猜测。规则是
src/main/resources/cuisinejournal/unification.json；候选越靠前越优先，只在实际存在且满足条件的候选中选代表。

## 使用

- 管理员设置“物品统一”：默认关闭百味纪规则，“开”启用。
- 装有 Kaleidoscope Compat 时协调其 COMPAT/UNITE；没有它也可独立工作。
- 游戏内切换重建受管数据包来源并重载，应用期间防重复，失败恢复原状态。
- 不扫描旧背包、不删除注册物品，处理已接标准新产出、配方、标签、掉落与种植路径。
- 未知机器、任意特殊 NBT、自动供液不保证通用转换。

## 自定义

config/cuisinejournal/unification.json 按相同组ID覆盖，组级替换，enabled=false可停特定组；修改后重载。
精确字段与例外见内置资源。不同内容物、部位、份量或容器不能仅凭名称视为等价。
keep_recipes等规则保留不同渠道；包装、种植和容器数量有专项，不是所有低优先配方都删除。
新增组须核获取、产量、副产物、种植、包装合回和下游，不只是图鉴显示。

## 功能边界

标签显示合组不扩实际配方接受范围。常驻纠错/掉落补丁可以默认模式生效，不表示整个统一已开启。
发现、品质、原料来源和生产归属也不是统一本身。配置契约见[配置与命令](../CONFIGURATION_AND_COMMANDS.md)。
